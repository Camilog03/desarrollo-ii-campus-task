# CampusTasks
Descripcion: lista de tareas.

## Requisitos

- Node.js 24.x

## Ejecución

Usa dos terminales.

### Terminal A (backend)

```bash
cd backend
npm ci
npm run start:dev
```

### Terminal B (frontend)

```bash
cd frontend
npm ci
npm start
```




## Resultado esperado

- http://localhost:3000/tareas devuelve 2 tareas.
- http://localhost:4200 las muestra.
